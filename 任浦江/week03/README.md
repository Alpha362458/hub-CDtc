# 第三周作业｜12 类语种识别

用字符级 RNN 判断一句话属于哪种语言。输入文本经清洗后逐字符编码，每句最多保留 40 个位置。模型通过 Embedding 和 RNN 计算每个字符的状态，排除补齐位置后做全局最大池化，再用 LayerNorm、Dropout 和线性层输出 12 类分数。训练使用交叉熵和 Adam。

## 运行

环境为 Python 3.12、PyTorch 2.14.1，使用 CPU。进入本目录后运行下面的命令。

```bash
python train_langid_v12.py --epochs 8
```

脚本默认读取 `data/langid/v12/` 中的训练、验证和测试数据。每轮结束后计算验证准确率，保存验证准确率最高的轮次到 `langid_rnn_v12.pt`。想保留已有权重，可以用 `--save` 指定另一个文件名。

## 数据与结果

| 项目 | 结果 |
| --- | ---: |
| 训练集 / 验证集 / 测试集 | 9,600 / 1,200 / 1,800 条 |
| 类别数 | 12 |
| 字符表大小（含 PAD、UNK） | 3,276 |
| 最佳轮次 | 第 8 轮 |
| 验证集准确率 | 97.00% |
| 测试集准确率 | 95.44%（1,718 / 1,800） |
| 测试集 macro-F1 | 0.9548 |

训练时只用 `train.csv` 生成字符表。`data/langid/vocab/vocab_v12.txt` 是同一映射的文本版。训练和重新加载权重后的测试结果一致。最常见的误判是西班牙语判成葡萄牙语（35 条），其次是葡萄牙语判成西班牙语（19 条）。

数据来源与许可见随附的数据卡。 [课程数据卡](data/langid/DATA_CARD.md)
